# Ghana AEA RCT — analysis code and slide deck

Stata code and Beamer slides for an RCT on feedback and training for agricultural
extension agents (AEAs) in Ghana.

- **T1** = Feedback, **T2** = Feedback + Training, **C** = Control. Assigned at district level.
- The estimation sample is **rainfed sites only**: the two irrigation districts
  (Kpong, Weta) are dropped from every estimation.
- Farmers N=373 (main ANCOVA), AEAs N=41, 4,120 farmer-rounds in the bi-weekly
  panel, **8 district clusters** (2 control, 3 T1, 3 T2).

---

## 1. What is and is not in this repository

| | Location | Tracked |
|---|---|---|
| Stata code | `do/` | yes |
| Slide source | `JICA-Ghana_full-analysis.tex` | yes |
| Tables and figures | `tmp/*.tex`, `*.pdf`, `*.eps` | yes |
| Intermediate data | `tmp/*.dta`, `*.gph` | no — regenerated by the pipeline |
| **Raw household data** | Dropbox `JICA Ghana/Data/` | **never** |

The raw data contains household identifiers and GPS coordinates. This repository
holds only symlinks to it. `.gitignore` ignores everything by default and allows
back only what belongs here, so `git add -A` cannot pick up raw data by accident.
Please keep it that way.

## 2. Setup

```bash
git clone https://github.com/Wataru-jp/ghana-aea-rct.git
cd ghana-aea-rct
```

Link the raw data to your own machine (you need access to the shared Dropbox folder):

```bash
DATA="$HOME/Library/CloudStorage/Dropbox/JICA Ghana/Data"   # edit to your path
ln -sfn "$DATA/Baseline"             Baseline
ln -sfn "$DATA/Endline"              Endline
ln -sfn "$DATA/Biweekly survey data" "Biweekly survey data"
```

Then point `global path` at the top of each do-file to your own clone. On Windows,
use the Windows line that is already there.

**Requirements**

- Stata 17 or later, plus `estout`, `balancetable`, `randcmd`, `boottest`,
  `dummies`, `ritest`, `grc1leg` (all via `ssc install`)
- LaTeX, only if you want to build the deck locally. Not needed if you work in Overleaf.

## 3. Running the analysis

```stata
do "do/run_endline_all.do"
```

This one file does everything: builds the data, runs every estimation, writes the
tables and figures into `tmp/`, and compiles the deck. It takes about an hour.

**Everything the deck shows is regenerated by this master file.** No table is
maintained by hand.

## 4. Folder layout

```
JICA-Ghana_full-analysis.tex   slide source (main document)
tmp/                           analysis output; the deck reads it via \input{tmp/...}
do/                            code behind everything in the deck;
                               run_endline_all.do is the authoritative run order
do/サブ/                       side analyses that do not feed the deck
```

The main `.tex` and `tmp/` sit in the same directory on purpose. Overleaf cannot
follow symlinks, and the base for relative paths differs between setups, so
keeping them side by side makes `\input{tmp/...}` resolve the same way locally
and on Overleaf. Please do not move them apart.

The header comment of `do/run_endline_all.do` lists which file produces what.
